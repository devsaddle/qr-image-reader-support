# 图中扫码 · 支持与隐私政策

这是图中扫码 QR Reader 的公开使用帮助、隐私政策和示例页面，不包含插件源码。原有入口按浏览器首选语言显示，未匹配时使用英文。顶部可手动切换，所选语言保存在当前浏览器；点击「跟随浏览器」可恢复自动选择。带语言目录的链接直接打开指定版本。

- 使用帮助：https://devsaddle.github.io/qr-image-reader-support/
- 隐私政策：https://devsaddle.github.io/qr-image-reader-support/privacy.html
- 繁體中文：https://devsaddle.github.io/qr-image-reader-support/zh-TW/
- English：https://devsaddle.github.io/qr-image-reader-support/en/
- 支持邮箱：devsaddle@gmail.com

网站不设置 Cookie，也不使用分析脚本或表单。手动选择的语言只保存在浏览器本地。页面由 GitHub Pages 提供，访问日志由 GitHub 依据其隐私政策处理。
